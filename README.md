# Jannis Janknecht

I am a student from Germany and I have been programming in my free time for a few years. I like to understand how things really work under the hood, so most of my projects are about building things myself like compilers, small Unix tools and bots for simple games such as Connect4 or Wordle.

Right now I am working on **jcc**, a compiler for my own language, written in C.
